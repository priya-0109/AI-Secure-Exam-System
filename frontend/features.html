Core Features

Every capability designed with one principle: maximum security without compromising usability for authorized users.

Core Features

🤖

AI Question Paraphrasing

The NLP engine automatically restructures each question's phrasing while preserving its semantic meaning, difficulty level, and academic intent. This ensures that even if a question is leaked early, its usefulness is significantly diminished.

NLP Semantic Preservation
🔒

AES Encryption

Advanced Encryption Standard (AES-256-CBC) is applied to all examination papers after approval. The ciphertext is stored and transmitted securely — without the correct decryption key, the content is computationally impossible to recover.

AES-256-CBC Zero Plaintext Storage
🔑

OTP Authentication

One-Time Passwords provide secure, temporary access gates. Each OTP is cryptographically generated, bound to a specific user, and expires after a configurable window. After use, the key is invalidated — it cannot be replayed or shared.

Time-Bound Single-Use
🖥

Secure Viewer

Papers are displayed through a hardened, read-only viewer that disables printing, copying, and screenshotting. Content is rendered in-session and never persisted to local storage. Access is only granted after successful OTP verification.

No Print/Copy Session-Only
📋

Activity Logging

Every significant event is automatically logged with a timestamp, user identity, IP address, and action type. The immutable audit trail enables post-incident investigation and creates accountability for every user in the system.

Immutable Log Full Audit Trail
👥

Role-Based Access Control

Four distinct roles — Faculty, Exam Cell, Security Officer, and Admin — each have precisely scoped permissions. No user can perform actions outside their designated role, creating strong separation of duties.

4 Roles Least Privilege
